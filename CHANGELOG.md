# Changelog

All notable changes to Advanced Pipez Utilities are documented in this file.

## [1.0.0] - 2026-08-16

### Added

- GregTech-style manual connection controls for Pipez pipes.
- An Advanced Pipe Wrench crafted from a standard Pipez wrench.
- GTCEu Modern-style targeting grids and connection-state icons.
- Directional pipe placement while holding a matching pipe or the Advanced Pipe Wrench.
- Automatic connection only to the pipe or compatible block targeted during placement.

### Changed

- Pipes no longer connect automatically to every adjacent compatible block.
- Right-clicking an extracting side now disables extraction before disconnecting it.
- Wrench interactions no longer play a sound, matching the standard Pipez wrench.

### Fixed

- Connection-state icons now render correctly from every viewing direction.
- Manual connection state is cleared when an adjacent compatible block is removed.
